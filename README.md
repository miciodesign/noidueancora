# Noi due, ancora

Sito statico del blog **Noi due, ancora** — intimità e vita di coppia dopo tanti anni insieme.

- `index.html` — home
- `chi-siamo.html` — pagina Chi siamo
- `articoli/` — un file HTML per articolo
- `css/style.css` — stile del sito
- `img/` — logo e favicon

Per aggiungere un articolo: copia `articoli/il-desiderio-non-sparisce.html`, cambia titolo, descrizione e testo, poi aggiungi la scheda nella home.
